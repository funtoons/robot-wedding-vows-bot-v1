Entry for the [One-Line Robot Wedding Vows](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b) bounty on [make.fun](https://make.fun).

The program writes a single original line of robot wedding vows to `/output/entry.txt` — a vow built on the classic wedding formula, with the machine twists landing in the last few words.

Run it with:

```sh
python3 main.py
```

Deterministic and offline: standard library only, no randomness, no network, no timestamps.
